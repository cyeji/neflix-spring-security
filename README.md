# 🎬 Netplix: 구독형 멤버십 프로젝트로 배우는 Spring Security

> **FastCampus 온라인 강의 실습 프로젝트**  
> [📚 강의 링크 바로가기](https://fastcampus.co.kr/dev_online_netflixproject)

Spring Security 기반의 실무형 구독 서비스 구현을 통해 인증/인가 원리를 깊이 있게 학습합니다.

---

## 📌 주요 기능

- 회원가입 및 로그인 (JWT 기반 인증)
- 구독 상품 등록 및 결제 연동 (페이먼트 모듈)
- 구독권 관리 및 만료 처리
- 관리자/일반 사용자 권한 분리
- Spring Security를 활용한 Role 기반 인가
- Redis를 이용한 Refresh Token 관리
- RestDocs 기반 API 문서화

---

## 🛠 사용 기술 스택

| Category       | Tech Stack                                 |
|----------------|---------------------------------------------|
